### Diubah
- **Installer (`install.sh`, `install.ps1`/`install.cmd`): alat AI lengkap.** Langkah alat AI kini menawarkan Claude Code CLI, Codex CLI, OpenCode CLI (`@opencode/cli`), Ollama (tanpa mengunduh model lokal), dan OpenClaw (Helpdesk) satu per satu; `--helpdesk`/`-Helpdesk` tetap diterima tetapi kini bawaan, `--tanpa-ai`/`-TanpaAi` melewati semuanya. Uninstaller `--alat-ai` ikut menghapus OpenCode CLI.
- **Data demo: semua modul ikut.** Superadmin demo mendapat semua definisi izin di `permission-list.js` (termasuk Mutu, SDM, Sarpras, Hemodialisa, Laundry, Ambulans, ICU, Kamar Operasi, Gizi, CSSD, UTD, Dashboard Eksekutif) tanpa daftar manual; peran faskes demo mendapat izin modul baru sesuai modul aktif segmennya. Entri izin bernama modul sama (Dashboard & Dashboard Eksekutif, Setting & Profile) digabung agar terbaca permission-sdk.
- **Manajemen Modul: preset segmen memuat modul baru.** Mutu & Akreditasi (klinik pratama, klinik utama, puskesmas, RS D–A), HR/SDM dan Sarpras (klinik utama, RS D–A), Manajemen Ambulans (puskesmas, RS D–A), Hemodialisa (RS C–A), Akuntansi (RS C); jumlah modul/fitur/bagian per segmen dan ringkasan segmen ikut diperbarui.
