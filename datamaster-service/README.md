# datamaster-service — Datamaster

Bagian dari monorepo [OpenSIMRS](../README.md) (paket `opensimrs-datamaster`).

Faskes, lokasi, pegawai & praktisi, tarif, penjamin, peran & pengguna, datamaster penunjang.

| | |
|---|---|
| Port lokal | `8096` |
| Awalan API | `/api/v3/datamaster` |

## Menjalankan

Jalankan dari **root repo** setelah mengikuti [Petunjuk Instalasi](../docs/INSTALLATION_GUIDE.md) (infrastruktur, `npm run install:all`, `.env` layanan, migrasi):

```bash
npm run dev:datamaster       # layanan ini saja
npm run dev           # semua layanan + frontend
```

- Konfigurasi dibaca dari `datamaster-service/.env`; templatnya `datamaster-service/.env.example`. Daftar variabel dan port acuan ada di [Petunjuk Instalasi bagian 5](../docs/INSTALLATION_GUIDE.md#5-konfigurasi-env-secara-rinci).
- Memakai SDK `@opensimrs/authorization-sdk`, `@opensimrs/model-sdk` dari `packages/` (dipasang sebagai salinan karena `install-links=true` di `.npmrc`). Setelah mengubah SDK, jalankan `npm run sdk:refresh -- datamaster-service` dari root.
- Skema database dikelola migrasi di `database/migrations/` (`npm run db:migrate`), bukan oleh layanan.
- Docker: dibangun dari root repo lewat `docker-compose.yml` (lihat [bagian 8](../docs/INSTALLATION_GUIDE.md#8-menjalankan-dengan-docker)).
- Uji unit: `npm --prefix datamaster-service test`.
